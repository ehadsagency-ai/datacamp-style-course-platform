# 🌲 Data Analyst Course App

An interactive React application for Data Analyst course with pixel-art data theme.

## Features

- Interactive modules for each level
- Charts and visualizations
- Mobile-responsive design

## Tech Stack

- React
- Vite
- Tailwind CSS
- Recharts

## Installation

npm install
npm run dev

## Deployment

Automatically deploys to GitHub Pages on push to main branch.
